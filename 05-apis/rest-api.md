# 6. APIs — The Invisible Communication (continued)

### 57. What are HTTP methods?
HTTP methods describe the intended action for a request, such as retrieving or changing a resource. They give clients and servers a shared vocabulary for how a request should be handled.

### 58. Why do we have GET, POST, PUT, PATCH and DELETE?
The methods distinguish common operations: GET retrieves, POST submits or creates, PUT replaces, PATCH partially updates, and DELETE removes a resource. Their defined semantics help clients, servers, caches, and intermediaries behave consistently.
