# Programming Curiosity 🚀

This repository is not about memorizing programming answers. It is about understanding WHY, WHAT, HOW, WHERE, WHEN, WHO, and WHAT IF behind the technology we use every day.

Every question is an opportunity to go one level deeper. Don’t just learn code. Understand what happens behind the code.

Before reading an answer, try to discuss the question with your team and make an assumption. Then compare it with the explanation and investigate anything that remains unclear.

For each new concept, use these seven lenses to ask follow-up questions:

- **WHY?** Why does it exist, and what problem does it solve?
- **WHAT?** What is it, and what are its parts?
- **HOW?** How does it work?
- **WHERE?** Where does it run or where is its data kept?
- **WHEN?** When is it useful, and when does it happen?
- **WHO?** Who uses, builds, or controls it?
- **WHAT IF?** What can fail, change, or happen at a different scale?

The answers apply the relevant lenses rather than repeating all seven headings for every question.
