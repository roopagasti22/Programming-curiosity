# 1. The Programming World

### 9. Why does a programming language need a compiler or interpreter?
A processor cannot execute most source code directly. A compiler translates code ahead of time, while an interpreter executes code through a runtime; many systems combine compilation, bytecode, and interpretation or just-in-time optimization.
