# 1. The Programming World

### 1. What exactly is programming?
Programming is the process of describing instructions and rules so a computer can perform a task. It includes designing the solution, writing code, testing it, and improving it when needs change.

### 2. Why was programming invented?
Programming lets people make machines perform repeatable calculations and tasks far faster and more consistently than doing them by hand. It has grown from controlling early machines into a way to build everything from websites to scientific tools.

### 3. Why can’t humans directly communicate with a computer?
People use flexible, ambiguous languages; processors execute precise machine instructions represented as bits. Programming languages and their tools translate human-readable intent into instructions the machine can execute.

### 4. How does a computer understand if, for, while and function?
Those words have meaning because a language defines their syntax and behavior. A compiler or interpreter parses them, checks their structure, and translates or executes the resulting operations.

### 5. Who decides what a programming language can do?
Language designers and standards groups define a language's syntax and semantics; communities and organizations may maintain specifications and implementations. Libraries and runtimes extend what developers can conveniently do, within the limits of the operating system and hardware.
