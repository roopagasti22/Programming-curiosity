# 1. The Programming World (continued)

### 6. Why are there hundreds of programming languages?
Languages are created to address different goals, hardware, domains, and preferences, and many evolve from earlier ideas. A language that suits embedded devices may make different tradeoffs from one designed for data analysis or web pages.

### 7. Why do we need Python, Java, JavaScript, C, C++, Go, Rust, etc.?
No single language is ideal for every task. Python is widely used for scripting and data work, JavaScript for browser applications, Java for many server and enterprise systems, and C, C++, Go, and Rust for different combinations of control, performance, and safety.

### 8. What makes one programming language different from another?
Languages differ in syntax, type systems, memory management, execution model, standard libraries, tooling, and ecosystem. Those differences affect how programs are written, deployed, maintained, and perform.
