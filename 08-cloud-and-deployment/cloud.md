# 10. Real-World Software (continued)

### 96. What is cloud computing?
Cloud computing provides on-demand access to computing resources—such as servers, storage, databases, and managed software—over a network. Customers provision resources without owning every underlying machine, but still make choices about cost, security, availability, and configuration.

### 97. What is AWS/Azure actually providing?
Providers such as AWS and Azure offer data-center infrastructure and managed services, including compute, storage, networking, databases, identity, and monitoring. They operate the underlying platform to varying degrees, while customers remain responsible for their application and for configuring their portion securely.
