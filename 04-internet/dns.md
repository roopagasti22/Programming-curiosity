# 5. What Actually Happens on the Internet?

### 41. What happens when you type google.com into a browser?
The browser interprets the address, checks relevant caches, and resolves the domain through DNS if needed. It connects to an IP address, establishes a secure connection for HTTPS, sends an HTTP request, and renders the returned page and resources.

### 43. What is DNS?
The Domain Name System is a distributed naming system that helps translate names such as `google.com` into records containing network information, commonly IP addresses. Caching makes repeated lookups faster, while authoritative DNS servers publish a domain's records.
