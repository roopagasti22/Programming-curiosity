# 9. Language Comparison (continued)

### 82. Why is JavaScript used in browsers?
Browsers implement JavaScript as a standard scripting language for interactive web pages, with APIs for events, networking, and page manipulation. It runs in a sandbox with browser permissions rather than unrestricted access to the user's system.

### 83. Why is Node.js able to run JavaScript on servers?
Node.js embeds the V8 JavaScript engine and provides server-side APIs for files, networking, and other system tasks. It uses an event-driven runtime that can handle many I/O operations without requiring one thread per request.
